# Facebook广告运营全流程操作手册
---
### **一、基础准备阶段**  
1. **账号矩阵建设**  
   - **账号选择**：推荐企业认证账号（BM）搭配「BM350老号」提高稳定性。新建主页可购买「带1000粉老主页」加速账号冷启动。  
   - **工具整合**：安装Facebook像素到独立站，同步配置Google Analytics跟踪数据。  
2. **素材库搭建**  
   - 准备至少3套创意模板（视频≤15秒、轮播图≥3张、图片+文案组合），垂直领域图片占比≥70%。

### **二、广告创建实操步骤**  
1. **广告系列设置**  
   ```markdown
   1. 进入Ads Manager → 选择目标（转化/流量/互动）。  
   2. 设置系列名称（建议格式：目标_产品_日期，如Conversions_Shoes_0824）。
广告组精确定义

受众定位
核心参数：年龄18-45岁，兴趣标签需通过Google Keyword Planner反向验证。
排除策略：排除7天内已购买用户，屏蔽竞品相关关键词。
版位优化
手动勾选：Instagram Feed为主（CTR最高），关闭低效版位（如Right Column）。
素材与文案适配

文案公式：痛点触发+解决方案+限时行动号召
例：户外露营帐篷 → “雨季露营总怕漏水？XX帐篷防水测试200小时！点击领取新手专属9折券”

素材规范：图片尺寸1200×628像素，视频封面需包含产品核心功能文字说明。
